{% if bracket.seeded %} Point at any team and its road to the trophy lights up. · {% endif %} A win in January pays the flat bonus plus that team's {{ term('lf', 'leveling factor') }} — except the wild-card round, which pays the visitor for the upset and the host nothing at all. · What each round is worth

Games nobody in the pool holds are dimmed. The accent rail on the left of each row is swing — how much the game actually moves the standings. A win by a team half the pool owns lifts half the pool together, so it barely changes the order; swing measures only the part that separates people, which is why a game everyone is on scores zero. {% if projecting %} The cyan percentage on each side is its chance of winning, from the same {{ '{:,}'.format(sim_count) }} simulated seasons as the forecast — modelled, not banked, which is why it is never the same colour as a score. {% endif %}
